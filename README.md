# Tactical Strike UE5

A small original tactical FPS prototype for Unreal Engine 5, inspired by competitive round-based shooters. It is not a copy of Counter-Strike 2 assets, maps, sounds, characters, or branding.

## Prototype features
- First-person movement and mouse look
- Hitscan rifle with magazine/reload
- Sprint + crouch
- Round-ready game mode skeleton
- Clean place to add original maps, materials, audio and multiplayer later

## Engine
Unreal Engine 5.6+

## Open
1. Clone the repository.
2. Right-click `TacticalStrike.uproject` and generate project files.
3. Open in Unreal Engine 5.6+.
4. Build the `TacticalStrikeEditor` target.
5. Start with the included FPS character/game mode.
