# Tactical Arena 3D — PC Edition

Target: Unreal Engine 5 / Windows desktop build.

## Current scope
- 3D arena prototype
- First-person movement
- Sprint, jump, crouch and dash
- Health, rounds, score and timer
- AI opponents using navigation
- Main menu and HUD
- Original fictional environment and assets

## Build
1. Install Unreal Engine 5 through Epic Games Launcher.
2. Open `TacticalArena3D.uproject`.
3. Add the project assets and C++ source.
4. Package > Windows > Windows (64-bit).
5. Launch the generated `.exe` from the packaged folder.

## Important
This repository is the source project, not a precompiled AAA executable. A true AAA game requires engine-side asset creation, lighting, animation, optimization, testing and Windows packaging.
